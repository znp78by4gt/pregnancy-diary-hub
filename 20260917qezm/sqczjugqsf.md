# 【食补】末伏前后，3种“神仙肉”端上桌，清火补虚又祛湿

> 更新时间：2026-09-17 (UTC+8)

**导 读**DAODU
“秋后一伏”的末伏快到了，老话说：**末伏不补，秋冬受苦！**但这时候的养生不能只顾着祛湿，同时也要兼顾润燥。

身体经过了一段时期的高温刺激和损耗，最需要的是清补，补而不滋腻，祛湿热的同时养脾胃、滋润身体。

这3种“神仙”级别的肉类记得端上餐桌，滋补美味，给大人小孩补够营养，顺顺利利迎接秋天！

**第1种：梭子蟹——高蛋白低脂肪**

“秋风起，蟹脚痒”，梭子蟹可是8月开海必尝的“第一口鲜”，味道肥美，吃法多种多样：葱油、白灼、清蒸、炒年糕等等，咋做都好吃~

**1.高蛋白**

螃蟹的蛋白质含量比猪肉、鱼肉都要高出几倍。

**2.高钙**

螃蟹的钙、磷、铁和维生素A的含量也较高。

**3.低脂肪**

脂肪仅是猪肉的1/11：每100g中含量仅3.1g，还不到猪肉脂肪含量的零头，减肥的朋友也可以放心吃哦。

**但食用梭子蟹要注意这几点：**

**1.**螃蟹性味偏寒，蒸螃蟹的时候可在螃蟹上撒一些生姜片或紫苏叶，若是用水煮螃蟹，则可把生姜片或紫苏叶加入水中。

**2.**体弱虚寒、平时容易胃部反酸、习惯性腹泻、胃胀以及患肝炎、严重胃病、心脑血管病、高血压病、动脉硬化、高血脂等病者更应少吃或不吃螃蟹，以免引起腹泻、消化不良甚至加重病情。

**3.**老人、小孩吃蟹时最好喝点姜汤、蘸姜末醋汁，以去其寒气。

**4.**螃蟹不可与柿子、西瓜、冷饮同食，以免过寒损伤脾胃。

**5.**吃蟹后1小时内不要喝茶，以免茶中的鞣酸与螃蟹中的蛋白质结合，不利于消化吸收，甚至引起腹痛、腹泻。

**第2种：鸭肉——祛湿又润燥**

在肉类里，鸭肉可是末伏的首选，为什么呢？

**1.清热补虚、滋补养胃**
鸭肉性味甘、寒，入肺、胃、肾经，有滋补、养胃、补肾、消水肿、止热痢、止咳化痰等作用。

和容易上火的牛羊肉不同，鸭肉性凉，凡体内有热的人适宜食鸭肉，体质虚弱、食欲不振、发热、大便干燥和水肿的人食之更为有益。

**2.高蛋白和微量元素**
每100克鸭肉含蛋白质16.5克，脂肪7.5克，钙11毫克，磷1.45毫克，铁4.1毫克。鸭肉中蛋白质含量比猪肉高，而脂肪含量却比猪肉低50%。

鸭肉是含B族维生素和维生素E比较多的肉类，钾、铁、铜、锌等元素都较丰富，鸭蛋中矿物质、维生素A含量也高于鸡蛋。

鸭皮的脂肪高，对于需要控制体重，或者是高血脂、冠心病患者，需要减少脂肪摄入，最好剥去鸭皮吃，这样可以使入口的鸭肉脂肪含量更低。

**推荐两道鸭肉美食：**
//
**1.冬虫夏草鸭**

做法：鸭子一只去毛及内脏，砍成大块，冬虫夏草10～20克，同蒸熟食用。

功效：有滋阴补虚、补肾益精、益肺止咳喘作用。健康人食之更能精力充沛，消除疲劳，久服有延年益寿之功。

//
**2.陈皮大鸭**

做法：鸭子一只去毛及内脏，蒸熟倒出汤汁，加入奶汤、鸡汤、酱油、料酒、胡椒粉拌匀，陈皮6克切丝放在鸭子上面，蒸熟食用。

功效：有健脾、开胃、补虚作用。适用于脾胃虚弱、食欲不振、营养不良等症。健康人食之更能精力旺盛。

**第3种：鲫鱼——健脾胃、祛湿**

**1.健脾利湿**
中医认为，鲫鱼味甘、性平，有健脾利湿之功，可治脾胃虚弱，纳少无力，对痢疾、便血、水肿、淋病、痈肿等也有食疗作用。

**2.高蛋白，补身体**
鲫鱼肉质细嫩，富含营养，每100g含蛋白质13~19.5g，磷200mg，钙54mg，还含有多种矿物质和维生素。许多地方妇女产后坐月子往往要喝鲫鱼汤，不但补益身体，还有助于增加乳汁。

**推荐两道鲫鱼美食：**
//
**1.鲫鱼百合汤**

材料：鲫鱼1尾，百合100g。冰糖、料酒适量。

做法：鲫鱼去鳞、鳃及内脏，洗净；锅中加水，放鱼烧开，加入料酒、百合，再用小火慢炖1小时，加入冰糖炖化即可。

功效：养肺止咳，益气止血。

//
**2.鲫鱼粥**

材料：鲫鱼1尾，粳米50g。陈皮末、胡椒末、姜、葱、盐各适量。

做法：鲫鱼洗净取肉，与粳米、陈皮末相合煮粥，至粥熟时，放入胡椒粉、姜、葱、盐调味即可。

功效：温中下气，健脾暖胃。
