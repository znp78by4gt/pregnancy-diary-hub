# 南通大学附属医院普通外科专科医师规范化培训招收简章

> 更新时间：2026-09-17 (UTC+8)

**按照国家专科医师规范化培训（以下简称“专培”）制度试点总体安排和招收工作通知要求，现将我院2020年专培招收简章介绍如下：**

**1****招收原则**公开公平、自愿参加、双向选择、择优录取。**2****招收专科及名额**
普通外科学专科：2人。
**3****招收对象**
1.完成住院医师规范化培训（以下简称住培）、取得合格证书并自愿参加专培的临床医师，专培招收来源可为外科、神经外科方向、胸心外科方向、泌尿外科方向、整形外科方向住培。

2.以往未参加过住培但已具备中级及以上专业技术资格的临床医师，根据单位工作需要、经单位同意后，可自愿申请参加专培，申报专科应与本人所在临床工作岗位相符合。
**4****培训年限**
2年。
**5****报名**登陆中国医师协会“专科医师规范化培训管理平台”（网址https://st.ccgme-cmda.cn/login.html）进行注册。请认真阅读《填报需知》，如实填写个人信息和志愿，提交报名信息。**6****材料审核**
材料审核通过者参加理论考核和临床综合能力考核。审核材料包括：

- 1.本人签名的报名表；
- 2.委托培训人员提交由委派单位签字盖章的同意书；
- 3.身份证原件及复印件；
- 4.住院医师规范化培训合格证书原件及复印件(未参加住培的提供中级及以上专业技术职称资格证）；
- 5.本科及以上学历（学位）证书原件及复印件；
- 6.《医师资格证书》原件及复印件。
**7****时间安排**
1.填报志愿：2020年7月20日-8月4日。

申请者登陆中国医师协会专培管理平台，查阅各培训基地招收简章，实名注册并完成志愿填报。

2.招收录取时间：2020年8月5日-8月18日。

理论考核时间为2020年8月6日上午，临床综合能力考核时间为2020年8月6日下午。

3.报到时间：2020年8月24日-8月31日。

经考核合格后录取的培训对象应如期报到。无故不报到或报到后无故退出者，3年内不得再次报名参加专培。逾期3周内未报到者，视为自动放弃。单位委派培训对象应与委派单位和培训基地签订三方培训协议，面向社会招收的培训对象与培训基地签订相关培训协议，培训协议应当在培训对象报到后两周内签订。

**8****待遇保障**
（一）委托培训学员在培训期间原人事（劳动）、工资关系不变，委托培训学员的工资仍由原单位发放。奖励性绩效从各级政府财政下拨的专科医师培训专项经费（按其使用范围）中支出，在此基础上我院予以1:1匹配。在规定培训时间内未按照要求完成培训或考核不合格者，培训时间可顺延，但顺延培训期间我院不再提供任何薪酬待遇。培训结束后，学员均回委托培养单位工作。

（二）社会化学员在规定的培训期间，奖励性绩效从各级政府财政下拨的专科医师培训专项经费（按其使用范围）中支出，在此基础上我院予以1:1匹配。在规定培训时间内未按照要求完成培训或考核不合格者，培训时间可顺延，但顺延培训期间我院不再提供任何薪酬待遇。培训结束后，均需自主择业。
**9****专科优势**
南通大学附属医院普外科为博士学位、硕士学位授予点，江苏省省级重点学科、省级临床重点专科。建科五十多年来，普外科十分重视科室的内涵建设，坚持以病人为中心、医疗为重点、技术为核心、教学为基础、科研为龙头的建科方针，既有德高望重的资深专家，也有享誉国内外的中青年专家。

普外科目前拥有五个病区，核定200张床位，设立四个三级临床专科，即肝胆胰脾外科、胃肠外科、甲乳外科、血管外科，下辖肝胆外科研究所、普外实验室。科室年门急诊量8万多人次，收治患者1万2千多人次，手术7千多人次，治愈好转率常年保持在95%以上。科室目前共有医护人员160位，其中医师65人；主任医师26人，副主任医师11人，教授12人，副教授13人；博士生导师2人，硕士生导师18人；博士后4人，博士18人。先后获得国务院特殊津贴的资深专家4人，省卫计委医学创新团队2个，省医学重点人才2人，省“333工程”中青年科学技术带头人5人，省高校“青蓝工程”中青年学术带头人培养对象1人，省“六大人才高峰”高层次人才培养对象10人等。

**专科特色**

1.肝胆胰脾外科：精准肝脏外科治疗技术，通过多种技术手段进行术前肝脏功能评估，使用规划系统进行手术规划，在腹腔镜下完成精准肝切除，同时常规开展肝脏肿瘤MDT，为肝脏肿瘤病人的治疗提供规范化、个体化的诊治方案，降低手术风险、缩短住院时间，提高总的生存率。肝胆管结石的系列治疗，八十年代率先在国内引进胆道镜治疗技术，并形成维胆道镜胆总管探查取石及微波碎石术+胆道镜球囊导管扩张术，目前已治疗患者1万多例，并多次获奖，其治疗水平达到国内领先。胰腺癌根治术，在省内率先开展的扩大的胰十二指肠切除术治疗用胰头壶腹部周围肿瘤，患者术后生存时间明显延长。常规开展腹腔镜胰腺手术、肝门部胆管癌根治术、门脉高压症的断流分流手术，腔镜下脾切除术、肝囊肿开窗引流术，腹腔镜胆道镜双镜联合开展胆囊胆道复杂手术，肝肿瘤射频消融治疗术等。

2. 胃肠外科：开展胃癌外科治疗为主的综合治疗，根据胃癌的不同术前分期，进行胃癌的规范化个体精准治疗、胃癌的规范化根治手术及快速康复治疗技术，缩短住院时间，进一步提高了胃癌患者术后的生活质量；运用外科微创技术治疗肥胖和代谢性疾病，效果显著。胃癌、大肠癌多学科诊疗（MDT）团队省内先进。大肠癌快速康复技术以及胃肠造口与伤口的管理技术省内领先；常规开展胃肠道肿瘤根治术、低位直肠癌的高难度保肛术、PPH术治疗重度痔等多种微创外科手术。

3. 乳腺甲状腺外科：开展的早期乳腺癌保乳手术及前哨淋巴结活检术，十年生存率90%以上；对乳腺癌进行包括手术、化疗、内分泌、放疗、基因靶向在内的综合治疗，实现肿瘤治疗的专业化、个体化，达到最佳治疗效果。乳腺微创旋切术是乳腺良性肿瘤创伤小、安全、美观的治疗方法。甲状腺癌根治性颈淋巴结清扫术及腔镜下甲状腺良恶性肿瘤根治术，在不影响手术效果的的情况下，更好保留了颈部和肩部外形及功能，提高患者的科生活质量。

4. 血管外科：开展多种微创技术治疗下肢静脉曲张，如微小切口、激光、药物、旋切等；开展下肢深静脉血栓的综合治疗，如滤器植入、插管溶栓、AngioJet吸栓、手术取栓等。
