# 关注母胎医学，保障优生优育 ——临床遗传与优生专题研讨会暨产前筛查 和产前诊断技术培训班顺利召开

> 更新时间：2026-09-17 (UTC+8)

“　　2015年11月20--22日，由苏州市立医院（苏州市妇幼保健院）生殖与遗传中心主办的临床遗传与优生专题研讨会暨产前筛查和产前诊断技术培训班在独具江南园林特色的南林宾馆隆重开幕。来自大陆和香港的多位专家和知名学者在本次会议进行精彩的学术演讲，与会的省内代表逾两百人。　　2015年11月20日下午，在苏州市立医院教育培训基地，生殖与遗传中心的李红教授主持召开了会前专家会议，针对当前最新的医学遗传学技术进展和经验，进行了热烈讨论。　　本次会议的开幕式由苏州市妇幼保健所王菁主任主持，卫计委妇幼处处长许珊瑶，香港中文大学妇产科学系教授蔡光伟、南京妇幼保健院副院长许争峰、南京医科大学教授刘嘉茵、苏州市立医院生殖中心主任李红出席开幕式。许珊瑶处长致辞，对到场的专家，知名学者，从医人员表示热烈欢迎，并预祝会议圆满成功。　　首先由苏州市卫生计生委妇幼处许珊瑶处长介绍《苏州市妇幼健康重点工作》，总结我市多年妇幼工作的成功经验，并强调单独二孩政策实施过程中，优生优育的紧迫感和重要性。作为政府惠民工程，计划于2016年苏州大市全面推广串联质谱技术用于29种新生儿代谢疾病的免费检查。开幕式结束后，精彩纷呈的学术报告接踵而至。蔡光伟　教授　　香港中文大学蔡光伟教授详细阐述《多种技术平台在遗传病诊断中的应用策略》。蔡教授介绍了目前遗传病诊断中用到的技术平台，重点涵盖了染色体微阵列技术，基于SNP的无创产前检测技术。他着重强调了这些技术平台的原理，适用临床症状，遗传咨询，优缺点，最新进展，为在场的医护人员带来技术前沿的洗礼。许争峰　教授　　南京医科大学附属南京妇幼保健院许争峰教授带来《单基因病的无创基因检测技术》的精彩演讲。许教授对临床表型复杂多样的单基因病攻坚克难，面对诊断困难，误诊率高等风险，自主创新研发新的无创单基因病检测技术。刘嘉茵　教授　　来自南京医科大学第一附属医院刘嘉茵教授为大家带来的报告是《高通量测序技术在PGD/PGS领域的应用》。刘教授向与会者详细介绍了胚胎植入前遗传学诊断/筛查（PGD/PGS）适应症，临床实践表明PGS单囊胚移植可改善临床结果。最后她和与会人员分享了单基因疾病PGD的临床案例。李亦学　教授　　上海生物信息技术研究中心李亦学教授带来精彩报告《生物大数据与精准医学》，李教授从国际前沿，国家战略层面，学术角度概括了大数据对精准医学的价值，主张临床、实验室、计算机生物信息专业人员的合作互动，以推动健康事业的发展，并介绍了我国即将启动的精准医疗国家专项。李教授的报告极具前瞻性和启发性，将本次大会的学术价值推到新的高度。李红　教授　　全新母胎技术给病患带来福音的同时，对我们的一线医护人员提出新的挑战，尤其是生殖相关的遗传咨询。苏州市立医院生殖与遗传中心主任李红教授带来具有实用意义的报告《生殖相关的遗传咨询》。报告主要从以下个方面给出专业解答：生殖临床遗传咨询的常见问题，遗传检测方法与比较，检测结果解读及风险预测等精彩内容。李红教授从临床一线角度出发，就各级医务人员临床工作中面临的很多细节问题，联系国内外进展，结合我中心的实践经验，进行详细阐述，受到与会学员高度评价。邓学东　教授　　苏州市立医院超声中心邓学东教授为大家带来的讲座是《规避产前超声风险之我见》。他丰富的临床经验，超声实践过程中的真知灼见，医患关系问题中的公正智慧给在场各位留下深刻印象。他详细介绍了产前超声指南，并从重要切面，标准手法，动态变化，鉴别手段，存在问题，相应对策等层面详细介绍。邓教授幽默风趣，与会者在欢声笑语中收获了超声经验和知识。王挺　高级实验师　　苏州市立医院生殖与遗传中心王挺演讲的题目为《高通量基因测序产前检测（NIPT）临床实践》，他详尽介绍了我院在获得卫计委高通量基因测序产前筛查和产前诊断试点单位后在NIPT临床实践的经验，取得的成果，以及在染色体微缺失微重复及单基因病等方面的研究新进展。目前中心完全自主运营的NIPT技术已公示荣获2015年江苏省妇幼系列新技术引进一等奖，苏州市新技术引进奖，以及苏州市科技进步奖。截止15年9月，该中心共计筛查了一万八千余例孕妇，对21号染色体非整倍体的阳性预测值高达90%以上，筛查灵敏度达99%，经产前胎儿染色体确诊，成功阻断了99例21三体、19例18三体、3例13三体、以及21例性染色体异常胎儿，使二级预防更高效降低苏州地区新生儿出生缺陷率，从而减轻社会经济负担，提高出生人口的健康素质。毛君　博士　　苏州市立医院中心实验室毛君博士作《苏州地区新生儿耳聋基因筛查》报告。毛博士着重介绍了自主研发基于SNaPshot技术的耳聋基因筛查技术平台在苏州地区1.6万新生儿中应用实践经验，发现苏州地区新生儿耳聋基因突变携带率高达16.6%，居全国之首，基因筛查为耳聋的早期干预提供了保障。李海波　助理研究员　　苏州市立医院生殖与遗传中心李海波给出报告《基于CNVplex技术的分子遗传学检测应用》，全面介绍了我中心拥有完全自主知识产权的CNVplex技术平台在单基因病、基因组病和染色体病的上的应用实践。特别就基层一线医护人员关心的流产组织非整倍体检测，从样本采集、运输到实验室检测和报告解读等方面进行了详细的说明。李晓兵　教授　　苏州市立医院影像科李晓兵教授作《胎儿脑发育异常的MRI诊断》报告，就如何从定位上决定哪种影像方法更合适临床诊断做出详尽解释，丰富的案例共享给了与会者和相关同行一次关于MRI的盛宴。黄伯贤　博士　　苏州市立医院生殖与遗传中心黄伯贤博士演讲题目为《环境内分泌干扰物对子代发育影响机制研究》。黄博士指出双酚A抑制神经细胞分化过程，为评估BPA对神经元细胞分化的影响提供了新的科学依据；BPA通过IGF-1抑制神经元细胞分化，而对IGF-1的调控是通过对SOX5的影响实现，BPA-SOX5-IGF-1信号通路为探讨神经发育提供了新的线索。姜纬　副主任医师　　苏州市立医院超声中心姜纬汇报题目为《超声软指标与染色体亚显微结构异常》，姜纬指出超声中心严格按照英国胎儿基金会等指南操作以确保临床诊断准确性，并通过多中心科研合作，对700余例软指标异常胎儿影像与产前遗传学检测结果统计后特别指出，超声软指标阳性胎儿染色体异常发生率高于软指标阴性胎儿，颈部软组织增厚与染色体异常关系最为密切。殷林亮　博士　　苏州市立医院超声中心殷林亮博士的演讲题目为《早孕期超声筛查及病例分享》，她着重讲述早孕期筛查的适用人群、筛查内容、临床意义，以及局限性。强调早孕期筛查在确定胎儿是否存活，准确估算孕周，确定胎儿数目尤其双胎特性，评估胎儿大体解剖结构以及胎儿染色体非整倍体风险方面的重要性，指出产前筛查要做到早发现早诊断早治疗，减轻孕妇心理生理创伤。　　会议于2015年11月22日圆满结束，“关注母胎医学，保障优生优育”的精神贯穿本次会议。希望一年一度的研讨会能对我省出生缺陷干预事业的发展起到推动作用。
