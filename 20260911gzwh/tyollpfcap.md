# 孕妇头痛，进了ICU，罪魁祸首竟是它！| 芳村医院

> 更新时间：2026-09-11 (UTC+8)

**孕妇头痛，进了ICU**

**罪魁祸首竟是它！**

在平常生活中，头痛是一种常见的症状，可能由于工作疲劳、情绪波动等原因引起。然而，许多人并没有重视它。但是，如果是年轻女性头痛，疼痛难以缓解，呈进展性，可要警惕了！38岁的黄女士，一向身体健康。却不曾想到，一次突发的头痛，竟让自己与死神仅有一步之遥！

**惊险病例回顾**

38岁的黄女士在11月4日上午开始出现头痛，曾有一过性言语不利、视物黑朦，阵发性左上肢麻木乏力，到外院就诊，做了抽血检查，提示炎症指标稍高，开了一些对症止痛的药物后回家。11月4日晚上约22:00患者开始出现发热，体温最高38℃，黄女士自行服用了布洛芬，想着或许是感冒发热头痛，吃了药就休息了。结果到了第二天凌晨，黄女士病情突然加重，分别在凌晨3:00、6:00出现四肢抽搐、口吐白沫等症状，每次持续2-5分钟，家里人连忙呼叫120送到了我院急诊。

**病例分析**

年轻女性急性头痛伴神经系统症状，首先应该排除急性脑血管病。急诊医生立即完善头颅CT平扫检查，发现病人双侧额叶存在散在的出血灶。黄女士年纪不大，又没有高血压病，怎么就出现脑出血了呢？而且还是多发散在的脑出血。经过仔细阅读患者的CT片，发现患者除了脑出血，还可能隐藏着另一个更致命的问题，那就是颅内一根重要的静脉可能发生了堵塞。给病人进一步做了颅脑MR检查，还真是一种少见的疾病“脑静脉窦血栓形成”。

脑内的静脉大血管堵塞，然后又导致继发性的脑出血，既要通血管又害怕再次出血，这处理起来可就棘手了。病人被收入了重症监护室，排除手术禁忌症后送介入室在气管插管全麻下行脑血管造影术+经导管上矢状窦静脉窦血栓去除术。术中所见及术后情况见下图：

在去除致命性血栓后，医生又进一步溯源求因，排除复发性栓塞事件的病因。导致黄女士发生静脉窦血栓的原因是什么呢？详细询问病史，黄女士既往有多囊卵巢病史，已婚已育，平素月经不规则，月经周期约60-90天，最近一次月经开始时间为2023年10月10日，这立即引起了医生的警觉，这迟迟不来的月经是不规律，还是怀孕了呢？入科后查血HCG为19032 IU/L，完善妇科彩超提示：宫内早孕（胚胎大小相当于4-5w）。

原来是妊娠所致！由于妊娠相关的脑静脉窦血栓缺乏特异性临床表现，大多表现为一种或多种高颅压相关的临床症状，比如头痛、急性或亚急性神经功能缺损、癫痫发作、意识障碍，因此易被误诊、漏诊。

**什么是脑静脉窦血栓**

**什么是静脉窦？**

脑血管除了我们熟悉的脑动脉系统，还有脑静脉系统；“窦”是指血管扩张部分，位于静脉就叫做静脉窦。静脉窦是静脉回流的主要通路，按它所在的部位回收相应区的静脉血。同时，人的脑每天大概产生400-500毫升脑脊液，大部分也是通过静脉窦回流到血液。所以静脉窦的通畅是维持正常血液和脑脊液循环的一个基础保证。

**什么是脑静脉窦血栓？**

脑静脉/静脉窦血栓（Cerebral Venous and Sinus Thrombosis, CVST）是指颅内静脉/静脉窦血栓形成所导致的脑静脉回流受阻和脑脊液循环障碍所引起的一系列临床综合征。脑静脉窦血栓是一种特殊类型的脑血管疾病，其发生率不足所有卒中的1%，往往容易被忽略。多见于妊娠妇女、服用口服避孕药的女性以及＜45岁的年轻人群。该病临床起病急，病情凶险，进展迅猛，预后差异很大，如果不及时治疗可能致残、致死。

**发生静脉窦血栓时有什么症状？**

头痛为脑静脉窦血栓最常见的临床症状，90％的患者会出现。40％的患者出现局灶性或全身性癫痫发作；颅内压升高造成的视盘水肿，可使视力进行性下降；出血、梗塞后继发的神经功能缺损如偏瘫、失语、感觉障碍等；静脉窦阻塞引起循环障碍局部症状如颜面肿胀、突眼、球结膜水肿等。

**什么人群容易患静脉窦血栓？**

1.感染性：继发于眼眶、面部、乳突、鼻窦的感染，以及化脓性脑膜炎、脑脓肿、败血症等疾病。

2.非感染性：多见于妊娠和围产期；口服避孕药；血小板增多症、红细胞增多症或先天性、后天性心脏病；严重脱水；外伤、消耗性疾病等。某些遗传性凝血功能异常如抗凝血酶缺乏、蛋白 C 和蛋白 S 缺乏、凝血酶原突变等，获得性因素如肾病综合征、抗心磷脂抗体综合征、系统性红斑狼疮等也可引起。

CVST患者中有54％的患者正在服用口服避孕药，34％处于遗传性或获得性血栓形成前状态，2％为妊娠妇女或产褥期女性，其他诱因包括血液系统疾病（12％）、感染（12％）及癌症（7％）。

**孕妇该如何预防静脉窦血栓？**

为避免或减少孕产妇静脉窦血栓的发生，针对其发病机制和危险因素，需要重点关注以下几方面：

1.完善孕前体检，排除各种容易导致静脉血栓栓塞的原因（如抗凝血酶缺乏、蛋白 C 和蛋白 S 缺乏、凝血酶原突变、抗心磷脂抗体综合征、系统性红斑狼疮），如有易栓倾向，应尽早咨询医生，评估风险，提早干预。

2.保持良好的生活习惯，孕前及产褥期应避免长期卧床，多饮水、适当活动，保持心情愉悦；

3.规范剖宫产术及促排卵治疗等指征，减少医源性高危人群的发生；

4.分娩期间脱水、过度呕吐、妊娠高血压和局部产科创伤会加重血栓形成前状态；贫血、感染和较年轻的妊娠年龄（14-25 岁）被认为是产科 CVST 发展的独立危险因素。因此产前、产时、产后重度脱水或大失血的产妇，应及时输液、输血，积极补充血容量，对于血FIB高、D-2聚体的患者，在没有明显出血情况下尽早活血、抗凝以及时纠正高凝状态；

5.对于育龄期女性不明原因的头痛抽搐，应十分警惕脑静脉窦血栓的形成！应及早就诊，并完善影像学检查。

及时发现是重点，早期预防是关键！年轻并不是资本，当出现反复头痛，尤其是妊娠期和围产期女性出现原因不明的头痛千万不要掉以轻心，需要及时就医，尽早明确病因才能更好地治疗。
